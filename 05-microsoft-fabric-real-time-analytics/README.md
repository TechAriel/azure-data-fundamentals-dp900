# Microsoft Fabric Real-Time Analytics

This exercise explores real-time data ingestion and streaming analytics using Eventstream and Eventhouse in Microsoft Fabric as part of the 
>Azure Data Fundamentals (DP-900) learning path.

## Components Implemented

- Fabric Workspace (with Fabric capacity enabled)
- Eventstream configuration (Yellow Taxi sample stream)
- Eventhouse creation
- KQL Database and managed table
- Stream-to-table ingestion
- KQL-based real-time querying

## Dataset Used

NYC Yellow Taxi – Real-Time Sample Stream  
(Continuously streaming taxi pickup events)

## Key Concepts Demonstrated

- Real-Time Hub as ingestion control plane
- Eventstream as streaming pipeline
- Eventhouse for durable event storage
- KQL database architecture
- Real-time aggregation using Kusto Query Language
- Stream-to-destination validation

## Engineering Relevance

This lab demonstrates how modern analytics platforms support streaming architectures by combining:

- Event ingestion
- Durable event storage
- Queryable time-series data
- Real-time aggregation

This architecture mirrors production streaming solutions built using event-driven data platforms.
