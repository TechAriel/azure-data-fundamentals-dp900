# Real-Time Analytics in Microsoft Fabric

## Overview

This lab explores Real-Time Intelligence in Microsoft Fabric by ingesting, storing, and querying streaming taxi ride data.

The focus of this lab was:
- Creating an Eventstream
- Persisting streaming data into an Eventhouse
- Querying data using KQL
- Validating real-time ingestion

> Part of the Azure Data Fundamentals (DP-900) learning path.

---

## Objectives

- Create a Fabric workspace with capacity
- Connect to a real-time streaming source
- Create an Eventhouse and KQL database
- Load streaming data into a table
- Query and analyze the captured data

---

## Technologies Used

- Microsoft Fabric
- Real-Time Hub
- Eventstream
- Eventhouse
- KQL Database
- Kusto Query Language (KQL)

## Key Learning Outcomes

- Understood how streaming data flows from Eventstream to Eventhouse
- Executed real-time queries using KQL
- Observed dynamic aggregation over live data
- Validated ingestion health using sampling queries
